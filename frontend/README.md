# 🎨 nQuire Frontend: Premium Business Intelligence Interface

nQuire is a high-performance, ChatGPT-style web interface built for professional data exploration. It provides a stunning, responsive experience with a focus on visual excellence and real-time interaction.

---

## ✨ Key Features

- **💎 Glassmorphism Design**: A modern, premium aesthetic using soft blurs and professional translucency.
- **⚡ Turbo Streaming**: Near-instantaneous business narratives that stream word-by-word (TTFT < 2s).
- **💠 Multi-Agent Pulse**: Visual real-time indicators for backend agent activities (Planning, RAG Discovery, SQL Generation).
- **📊 Interactive Results**: Seamlessly transitions between chat narratives, generated SQL insights, and interactive data tables.
- **🌗 Responsive Layout**: Optimized for both desktop and mobile high-end business workflows.

---

## 🛠️ Technology Stack

- **Core**: React 18+
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (Custom Variable-Based Design System)
- **Animations**: CSS Transitions & Micro-interactions
- **Communication**: Server-Sent Events (SSE) for token-wise streaming

---

## 🚀 Quick Start

### 1. Installation
```bash
npm install
```

### 2. Launch
```bash
npm run dev
```
